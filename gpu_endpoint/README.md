# CineForge GPU endpoint

Requires a GPU Space runtime. Configure Space secret ENDPOINT_TOKEN, then configure CineForge HF_ENDPOINT_URL to this Space /generate and HF_TOKEN to the same token.

Choose GPU hardware in Space settings. GPU availability, quotas and charges are provider dependent. This is a deployment template only; no GPU is provisioned by this repository.
