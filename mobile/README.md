# CineForge GPU Companion
Java/Gradle Android starter for controlling a user-owned CineForge inference host. No third-party video-generation API is used.

Current starter: host URL entry, prompt field and honest placeholder connection/render status. API integration remains pending.

Open the mobile folder in Android Studio or an Android Gradle environment to build. This commit does not trigger GitHub Actions.

Next milestone: authenticated host endpoints for status, job submission, progress, previews and export downloads. Use HTTPS and authentication before exposing any GPU server publicly.
